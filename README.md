# Jeu du Royaume : la version à jouer

Le jeu, en un seul fichier (`index.html`), pour y jouer dans le navigateur, sur téléphone ou sur ordinateur :

**https://gimenezjorys.github.io/royaume-jeu/**

Tiens le téléphone en largeur. Pour l'avoir comme une appli : dans Safari, Partager puis « Sur l'écran d'accueil » ; dans Chrome, le menu puis « Ajouter à l'écran d'accueil ». La partie est gardée dans le navigateur.

Ce fichier est fabriqué à partir du dépôt du jeu (`npm run fichier`) et remis ici après les mises à jour. Le village partagé et les notifications ne marchent pas dans cette version.
