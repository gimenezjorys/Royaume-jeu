# Jeu du Royaume : la version à jouer

Le jeu, en un seul fichier (`index.html`), pour y jouer dans le navigateur, sur téléphone ou sur ordinateur :

**https://gimenezjorys.github.io/Royaume-jeu/**

Tiens le téléphone en largeur. Pour l'avoir comme une appli : dans Safari, Partager puis « Sur l'écran d'accueil » ; dans Chrome, le menu puis « Ajouter à l'écran d'accueil ».

À l'arrivée, crée ton compte (pseudo : 3 à 20 lettres sans accent, chiffres ou _, sans espace ; mot de passe : 8 caractères au moins) ou joue sans compte. Sans compte, la partie est gardée dans le navigateur ; avec un compte, elle est aussi gardée en ligne (tu la retrouves sur un autre téléphone) et tu peux jouer au village partagé avec tes amis, grâce au serveur du village (Cloudflare).

Ce fichier est fabriqué à partir du dépôt du jeu (`npm run fichier`) et remis ici après les mises à jour. Les notifications ne marchent pas dans cette version : elles demandent le service worker (`sw.js`) de la version publiée sur Netlify.
